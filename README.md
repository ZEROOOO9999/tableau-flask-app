# Global AI Adoption Dashboard

A Flask web application that integrates an interactive Tableau Public Dashboard and Story for analyzing global AI adoption.

## 📌 Project Overview

This project provides a simple web interface to explore global AI adoption data through interactive visualizations created using Tableau Public.

The Flask application acts as the web interface and embeds the existing Tableau Dashboard and Story.

## 🚀 Features

- 🏠 Simple and user-friendly homepage
- 📊 Interactive Tableau Dashboard
- 📖 Interactive Tableau Story
- 🔗 Flask-based navigation
- 📱 Responsive web interface
- 📈 Data visualization using Tableau Public

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML**
- **CSS**
- **Tableau Public**
